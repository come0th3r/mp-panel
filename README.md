# MP Panel

Веб-панель для Minecraft Java. Панель устанавливается на одном Linux-сервере и управляет игровыми хостами через агенты. Чтобы подключить хост, достаточно указать SSH-доступ в интерфейсе и проверить отпечаток ключа. Панель установит Docker и агент; дальнейшие команды передаются по HTTPS с mTLS.

## Установка

Нужен Debian или Ubuntu на x86_64, права root или sudo и доступ в интернет. Установщик собирает приложение на сервере, поэтому первая установка занимает время и требует места для Docker-образов.

Скачайте установщик из [релиза v0.3.1](https://github.com/come0th3r/mp-panel/releases/tag/v0.3.1) и запустите:

```bash
curl -fL https://github.com/come0th3r/mp-panel/releases/download/v0.3.1/setup.sh -o setup.sh &&
sudo bash setup.sh
```

Установщик спросит адрес панели, адрес для агентов и email администратора для официального каталога Paper. Он установит Docker при необходимости, проверит контрольную сумму архива, создаст `.env` со случайным паролем базы и запустит Docker Compose. По умолчанию панель доступна на порту `8080`, агенты подключаются к `8443`, файлы приложения размещаются в `/opt/mp-panel`.

После установки откройте указанный адрес панели и создайте владельца с токеном, который выведет установщик. Затем добавьте игровой хост во вкладке «Хосты». Согласие с Minecraft EULA требуется при создании игрового сервера.

С Windows можно запустить тот же установщик по SSH:

```powershell
.\setup.ps1 -Address SERVER_IP -User root
```

Файл `setup.ps1` доступен в релизе. Он использует установленный OpenSSH; проверка ключа хоста и запрос SSH-пароля выполняются обычным SSH-клиентом.

DNS, проброс портов и HTTPS-прокси настраиваются отдельно. Подробности и установка из исходников описаны в [руководстве по развёртыванию](docs/DEPLOYMENT.md).

## Обновление

Скачайте установщик нужного релиза и выполните ту же команду установки. Для нестандартного пути добавьте `--directory /путь/к/панели`. Существующий `.env`, действующие Compose-файлы, учётные записи и конфигурации сохраняются. Новая версия собирается, пока прежняя панель работает. Перед переключением установщик останавливает API и worker, сохраняет PostgreSQL, том `panel-data`, исходники и прежние образы. Игровые серверы и шлюз продолжают работать.

Если сборка или запуск новой версии завершаются ошибкой, установщик возвращает прежнюю версию. Копии остаются в `/var/lib/mp-panel-updates` с доступом только для root. После аварийного завершения процесса может потребоваться ручное восстановление: команда и ограничения описаны в [руководстве](docs/DEPLOYMENT.md#обновление-и-откат). Отдельные копии миров по-прежнему нужны: обновление панели их не создаёт.

Владелец видит небольшой индикатор нового релиза. Его можно скрыть до следующей версии; подробности и ручная проверка находятся в «Настройки → Обновления». Обновление запускается администратором через терминал.

### Переход со старой версии без обновлений в интерфейсе

Наличие раздела «Обновления» в старой панели не требуется. Обновление выполняет новый установщик, скачанный из последнего стабильного релиза. Старый `setup.sh`, оставшийся от первоначальной установки, для этого не используйте.

Подключитесь по SSH к машине, где установлена сама панель. Для стандартного каталога `/opt/mp-panel` выполните:

```bash
sudo test -f /opt/mp-panel/.env &&
curl -fL https://github.com/come0th3r/mp-panel/releases/latest/download/setup.sh -o setup.sh &&
sudo bash setup.sh --directory /opt/mp-panel
```

Первая команда проверяет наличие настроек существующей панели. Если файл не найден, следующие команды не выполняются. При другом каталоге установки замените `/opt/mp-panel` в обеих строках с этим путём.

Этот способ предназначен для установки через штатный Docker Compose: контейнеры `api` и `worker` должны существовать, а PostgreSQL должен работать. Завершите текущие операции установки серверов, загрузки и изменения файлов перед обновлением. Игровые серверы останавливать не требуется.

Новый установщик найдёт существующий `.env` и применит обновление с резервной копией и откатом, описанными выше. Повторно создавать владельца или подключать хосты не нужно. Не удаляйте `.env` и не выполняйте `docker compose down -v`: эта команда удаляет тома с данными. Если установщик предлагает заново указать адреса панели и email, прервите его и проверьте каталог установки.

После завершения обновите страницу панели. Для новых функций файлового менеджера обновите агенты в разделе «Хосты → Обновить агент», указав SSH-доступ к существующему хосту. Если обновление прервалось, используйте команду восстановления из сообщения установщика; порядок описан в [руководстве](docs/DEPLOYMENT.md#восстановление-прерванного-обновления).

## Возможности

- Создание, запуск, остановка и перезапуск серверов в Docker. Контейнеры восстанавливаются после перезагрузки хоста, если сервер не был остановлен вручную.
- Каталог Vanilla, Paper, Fabric, Forge, NeoForge и Spigot из официальных источников. Пользователь выбирает Minecraft, сборку или загрузчик и Java; ядро скачивается при установке. Можно загрузить собственный JAR.
- Консоль, `server.properties`, загрузка модов и плагинов, смена ядра и резервные копии.
- Файловый менеджер: выделение, копирование, вырезание и вставка, перемещение, переименование, массовое удаление и распаковка ZIP/RAR. Можно загружать несколько файлов или целый каталог, в том числе перетаскиванием из проводника. Формы создания каталога и загрузки открываются по кнопке.
- Метрики CPU, RAM, диска и I/O с историей в PostgreSQL.
- Роли, TOTP, коды восстановления и аудит. Оператор полностью управляет назначенными ему серверами, включая ядро, файлы и удаление.
- Игровые домены через mc-router или Gate Lite. Можно добавить маршрут к уже существующему серверу по IP и порту без установки агента.

Список версий обновляется независимо от установленных серверов. Обновление каталога не меняет их ядра. Профили и источники описаны в [документации каталога](internal/catalog/README.md), настройка доменов в [руководстве по шлюзам](docs/GATEWAY.md).

Для изменения файлов остановите игровой сервер. За один раз можно выбрать до 100 объектов или загрузить до 100 файлов, каждый до 256 МиБ. Структура загружаемого каталога сохраняется; пустые каталоги создаются отдельно. Существующие файлы не перезаписываются. Копирование в тот же каталог создаёт файл с новым именем. Shift выделяет диапазон, Ctrl/Cmd + C, X и V работают внутри файлового менеджера.

Распаковка поддерживает ZIP и однотомные RAR без пароля: до 10 000 записей и 2 ГиБ после распаковки. Для RAR размер словаря ограничен 64 МиБ. Ссылки и пути за пределами каталога сервера отклоняются.

## Устройство проекта

```text
apps/web/             React, TypeScript, Vite
cmd/mp-api/           HTTP API и отдельный порт агентов
cmd/mp-worker/        очередь подключения хостов по SSH
cmd/mp-agent/         агент игрового хоста
internal/catalog/    каталоги версий и проверка артефактов
internal/agent/      Docker, файлы, копии и метрики
internal/api/        управление, авторизация и маршруты
internal/networking/ адаптеры игровых шлюзов
internal/store/      PostgreSQL и схема базы
deploy/             установщики и конфигурации Compose
scripts/             сборка файлов релиза
```

Задания хранятся в PostgreSQL. Агент забирает команды, исполняет операции с локальным журналом повторов и отправляет метрики. Игровой трафик проходит через игровой хост или шлюз. Интерфейсы описаны в [контракте API](docs/API_CONTRACT.md).

## Ограничения

Панель рассчитана на собственные хосты и доверенных администраторов. Игровые хосты поддерживаются на Debian и Ubuntu x86_64. Полная совместимость каждого ядра, мода и мира не гарантируется. Перед сменой ядра нужна резервная копия.

Копии хранятся на игровом хосте и не защищают от потери этого хоста. Дисковая квота не ограничивает запись жёстко. Google/OIDC, скачивание модов из сторонних каталогов, S3-копии и автоматическая настройка VPN или firewall пока не реализованы.

Установщик не создаёт игровые серверы и не принимает EULA за пользователя. Обычный HTTP допустим для локальной установки; для доступа через интернет настройте HTTPS. При отключении хоста из панели доступ агента отзывается, но сам агент остаётся на машине.
